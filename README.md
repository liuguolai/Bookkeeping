# 口袋账本

单机多币种记账 App，工作名称为“口袋账本”。React 与 TypeScript 实现界面和记账规则，Capacitor 提供安卓、iOS 原生工程。无需注册或业务服务器。

安卓开发版：[下载安装包 0.1.8](artifacts/pocket-ledger-0.1.8-debug.apk)（约 12.8 MiB，Android 7.0 及以上；最低版本尚未实机验证）。将 APK 传到安卓手机后打开安装，首次运行创建账本即可使用。安装包不含测试记录。

PWA 网页版：[下载 0.1.9 部署包](artifacts/pocket-ledger-0.1.9-pwa.zip)（约 183 KiB）。已补齐主屏幕安装、全量离线缓存、主动更新、持久存储申请和浏览器备份文件保存入口。使用与部署见 [PWA 部署与验收](docs/PWA部署与验收.md)。正式手机使用需要固定 HTTPS 网址；本地完成不代表已经上线。

## 当前实现

- 本地多账本、默认和常用币种、归档、账本删除撤销。
- 收入、支出、同币种部分退款、编辑、回收站和新记录草稿。
- CNY、HKD、MOP、USD、EUR、GBP、JPY、SGD；独立统计、独立月预算和分类预算。
- 备注搜索、日期区间、分类、支付方式、类型与币种筛选。
- 月度统计对比：收入、净支出、收支结余、分类增减、预算剩余或超支；当前月支持截至今日与上月同期对比、整月对比，历史月份比较完整月份，各币种独立计算。
- 分类及支付方式新增、重命名、启停；分类可选择 31 个内置图标。
- 新账本默认包含长辈、小孩；新增支出分类时可从 12 个家庭与日常推荐分类中选取名称和图标，已有账本也可使用。
- 点击年月直接输入年份、点选月份，支持回到本月。
- 记录详情“再记一笔”、今天/昨天/前天快捷补记、保存并继续；复制和编辑记录不会清除其他未完成草稿。
- 按分类显示常用备注，使用次数高的优先，次数相同按最近使用排序，点击填入后仍可编辑。
- 分类置顶、同组箭头排序和电脑拖动排序；列表与图标编辑分开显示。
- 安卓返回键先收起键盘、再处理弹窗，未保存记录确认；记账保存栏保持在键盘上方。
- 打开记账自动聚焦金额；手机保存栏分为两排，草稿和连续保存位于上排，保存记录独占下排，按钮文字不换行。
- 金额支持加减算式和加、减、等号、清空按钮，例如 `18+12.5`；实时预览合计，保存时自动计算，未完成算式可存草稿。按币种精度计算，不四舍五入，不支持乘除或括号。
- 提高分类、输入提示、明细日期与备注的文字对比度，增大手机明细辅助文字；分类网格和输入区随宽度调整，支持窄屏及放大字体布局。
- 有未备份记录且已超过 7 天时显示页面备份提醒，无后台通知权限。
- 常用模板：按账本保存收支类型、币种、可选金额、分类、支付方式和备注；使用时日期更新为今天，确认后保存，不覆盖已有草稿。每账本最多 20 个模板。
- 升级前自动留存原始数据，本机最多保留最近 3 份保护副本；支持手动创建、整库恢复、恢复前自动留存，以及启动失败后的恢复入口。
- CSV 明细导出、密码加密备份（含模板）、恢复预览、重复恢复确认；兼容旧版备份。
- 原生端加密 SQLite；PWA 和浏览器开发预览使用 IndexedDB，**浏览器存储不具备原生数据库加密**。

需求基线见 [需求文档](docs/记账软件需求文档.md)，验证范围和剩余事项见 [实现与验证记录](docs/实现与验证记录.md)。当前代码不代表已经完成应用商店发布或 iOS 真机验收。

## 本地运行

需要 Node.js 22 以上。

~~~powershell
npm ci
npm run dev
~~~

按终端提示打开本机地址。开发预览的本地 HTTP 服务仅用于加载调试页面，手机安装包内置页面资源，不依赖它。

~~~powershell
npm run check
npx playwright install chromium
npm run test:e2e
~~~

浏览器测试使用独立临时数据，覆盖桌面和手机尺寸。浏览器验证不等于原生 SQLite 或设备验收。

## 安卓构建

需要 Java 21、Android SDK Platform 36 和对应构建工具。当前机器 SDK 位于 D:\Android\Sdk。构建脚本只为当前进程设置环境变量，不修改系统 Java。

~~~powershell
.\scripts\build-android.ps1 -SdkPath 'D:\Android\Sdk' -JavaHome '你的 JDK 21 路径'
~~~

若项目内已有 .local/tools/jdk21，脚本会自动选择其中的便携 JDK。输出位于 artifacts/pocket-ledger-<package.json 版本号>-debug.apk。该安装包为调试签名，适合测试；正式签名和分发需另行配置。

当前环境 Java 到 Maven 的 TLS 连接曾失败，临时构建适配器位于忽略目录 .local。它仅监听 127.0.0.1，通过系统 curl 校验 HTTPS 从官方仓库下载。产品代码不依赖该工具，普通网络下直接使用 Gradle Wrapper。

## iOS 构建

已生成使用 Swift Package Manager 的 ios/App/App.xcodeproj，部署目标为 iOS 16.0。需要在 macOS 上使用兼容 Xcode，安装 npm 依赖后执行 npm run native:sync，再用 Xcode 选择开发团队、连接设备并构建。Windows 无法验证 iOS 编译、签名和设备行为。

## 数据设计

金额存为对应币种最小单位的安全整数：CNY 28.50 为 2850，JPY 1200 为 1200。所有计算必须指定币种，不提供混合币种总金额。退款关联原支出，累计不得超额，跨月退款计入退款月份。

当前运行状态为 schema 2，读取 schema 1 时补充空模板列表；升级保护先于数据迁移和业务写入，失败则停止写入。未知未来版本拒绝读取。运行状态使用带版本号的文档，原生端存储在加密 SQLite 的一个状态行内，以数据库事务提交；浏览器使用 IndexedDB 事务。仓库串行处理修改、提交前校验完整关联关系，并用 revision 防止陈旧页面覆盖。此方案优先保证首版原子性；大量记录的性能需实测，必要时迁移至分表存储。

备份使用 PBKDF2 SHA-256 派生密钥和 AES-GCM 认证加密，每份文件独立随机盐及 IV。加密文件恢复仅创建新账本，映射所有引用，不覆盖已有数据。本机保护副本恢复则还原全部账本，操作前自动保留当前状态，需在界面中确认。文件保留币种定义和精度，未知定义整份拒绝。加密方案代码已有测试，未经过独立安全审计。

Android 关闭自动云备份及设备迁移，iOS 配置数据库目录排除自动备份；平台实际效果仍须分别测试。应用未配置业务网络请求、账号或遥测。导出到系统分享不等于文件已在外部安全保存，请实际确认保存位置。
