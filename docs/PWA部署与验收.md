# 口袋账本 PWA · 0.1.9

> 0.2.0 更新：PWA 已加入可选加密云同步。以下为原本地模式部署说明；启用云同步请使用完整仓库和 [云同步部署与验收](云同步部署与验收.md)，并绑定 D1，静态 ZIP 不包含后端。

这是可安装到主屏幕的本地记账网页。无需 Apple 开发者账号、签名续期或业务服务器；首次加载和更新需联网，离线文件就绪后可记账、统计、导出与恢复本地备份。没有账号、云同步或混合币种总金额。

## 构建和本地预览

```powershell
npm ci
npm run build
npm run preview:pwa
```

Windows 生成部署 ZIP 可运行 `./scripts/package-pwa.ps1`（会先重新构建，并输出 SHA-256 校验文件）。

打开 http://127.0.0.1:5174/ 。这是生产 PWA 预览；`npm run dev` 的 5173 开发页面故意不注册离线缓存，避免缓存旧代码干扰开发。两者端口不同，账目不自动共享，需导出加密备份再导入。不要为了更新程序清除网站数据。

`localhost` 和 `127.0.0.1` 仅用于当前电脑测试。手机访问电脑的普通局域网 HTTP 地址不满足 Service Worker 的安全要求；手机正式使用需要 HTTPS。手机自身的 127.0.0.1 也不是这台电脑。

## 静态托管

### Cloudflare Workers（当前部署方式）

GitHub 仓库选 `liuguolai/Bookkeeping`，生产分支 `main`，根目录 `/`，构建命令 `npm run build`，构建环境变量 `NODE_VERSION=22`。部署命令使用：

```text
npx wrangler deploy --assets ./dist --name pocket-ledger
```

仓库根目录的 `wrangler.jsonc` 指定项目名称、静态资源目录和 `compatibility_date`。兼容日期固定为 `2026-10-06`，与当前部署工具支持的日期一致；它是 Workers 运行时兼容规则的基准，不是应用到期日期。无需在控制台的部署命令中重复填写日期。暂时关闭 Preview builds，日常使用正式部署地址。

依赖安装、网页构建、上传部署是三个独立阶段。`Build command completed` 仅代表网页已构建；还需等待部署成功并实际打开 HTTPS 网址。修改 GitHub `main` 后查看最新提交的部署，不要反复重试旧提交。

参考：[Cloudflare 兼容日期](https://developers.cloudflare.com/workers/configuration/compatibility-dates/)。

### Pages、Netlify 等静态托管

构建命令：`npm run build`；输出目录：`dist`；无需环境变量、数据库或服务器函数。部署包 `artifacts/pocket-ledger-0.1.9-pwa.zip` 的顶层就是站点文件，解压后上传全部内容，不要再多套一层 dist。

Cloudflare Pages、Netlify 等静态平台可使用上述构建配置，也可上传构建文件。选择平台时先确认自己的网络能稳定访问其默认域名。可先用平台提供的 HTTPS 地址，不要求购买自定义域名。平台的免费额度和服务条件以其当前规则为准。

部署要求：

1. 使用一个长期固定、专供此应用的 HTTPS 域名或子域名，发布到原来的站点。不要把每次部署的临时预览地址作为日常记账入口。
2. 一次完整发布同一构建的所有文件。不要单独覆盖 sw.js 或只上传 HTML。若平台不是原子发布，先上传资源，最后发布 sw.js。缺失资源应返回 404，不能把 JS/图标请求兜底成 index.html。
3. HTML、sw.js、manifest 不长期缓存；带哈希的 assets 可设一年 immutable。`public/_headers` 随构建输出，采用 Cloudflare Pages/Netlify 格式。其他平台需在控制台设置等效响应头，不应把 _headers 当成网页提供。
4. sw.js 返回 JavaScript 类型，manifest 返回 `application/manifest+json`，图标返回 `image/png`。不需要额外的 Service-Worker-Allowed 头，worker 和安装入口放在同一目录。
5. 应用资源均来自同站点，不使用 CDN 字体、分析脚本或第三方业务接口。建议保留 _headers 中的 CSP 和安全头；托管平台仍可能记录 IP、浏览器等访问日志。

构建也支持 `/ledger/` 这样的子目录：完整 dist 放入同一目录，从带尾部斜杠的 `/ledger/` 进入；为 `/ledger` 配置重定向到 `/ledger/`，并把 _headers 内的根路径规则改成该子目录。不同子目录仍共享同一来源的 IndexedDB，**不能把同域名不同路径当成互相隔离的账本实例**。

## iPhone / iPad 安装

1. 用 Safari 打开正式 HTTPS 网址。
2. 分享 → 添加到主屏幕；若出现“作为网页 App 打开”，开启它。
3. 从桌面图标重新打开，保持联网直到页面显示“离线已就绪”。
4. 创建或导入账本。首次使用桌面入口时确认数据是否存在，不假设它与之前的浏览器窗口自动共享存储。
5. 设置 → 安装与离线使用 → 申请持久存储。浏览器可以拒绝；拒绝不妨碍记账，也不代表数据已有备份。

安装指导参考 [Apple iPhone 使用手册](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios)。浏览器菜单文字会随系统版本变化。

## 数据、备份与换机

- 网页版保存在 IndexedDB，继续使用已有数据库名称以兼容旧网页数据；本地数据库未启用原生版的加密。加密导出的备份使用既有 PBKDF2 / AES-GCM 方案。
- 设置 → 导出与备份 → 输入密码 → 生成加密备份。生成后有可重复点击的“下载文件”，支持文件分享的浏览器另有“分享或存储到文件”。Safari 系统分享中可选择“存储到文件”；自动下载可去 Safari 下载列表或“文件”应用确认。
- 分享取消后仍可下载。生成时间是快照时间；后来新增的账目需要重新生成。备份含有效记录、分类、支付标签、预算和模板，不含草稿、回收站；CSV 是明文分析文件，不能恢复账本。
- 换手机、换域名、换浏览器前：把加密备份放到手机外 → 新入口选择文件、输入密码、校验预览 → 恢复为新账本 → 核对条数和各币种金额。旧账本不会被覆盖，设备之间不自动同步。
- 本机保护副本与账目处在同一存储中，不能替代外部备份。清除网站数据、卸载、设备丢失、存储回收都可能造成丢失；持久存储获准也不能防止主动清除或设备损坏。

存储策略参考 [WebKit 存储政策](https://webkit.org/blog/14403/updates-to-storage-policy/)。PWA 不存在免费开发签名的 7 天到期问题，但不能把这一点解释为本地数据永久不会丢失。

## 打开过一次后出现 ERR_FAILED

2026-10-10 已修复托管平台将 index.html 重定向到首页时的缓存兼容问题。请发布最新 main；保留网络连接，关闭该站点的所有标签页和桌面应用窗口，再重新打开。浏览器下载新 Worker 后会修复已有程序缓存，必要时稍后再刷新一次。不要清除网站数据或 IndexedDB，否则会删除本机账目。若仍失败，可在浏览器开发者工具中仅更新/注销该站点的 Service Worker 后重开，不要使用“清除网站数据”。

## 离线与更新机制

构建会生成 sw.js，按完整文件内容生成构建标识。安装时先把所有程序文件缓存齐全，成功后才可激活。离线导航使用缓存的应用入口，包含备份等功能的代码也在初始缓存范围内；不缓存账目文件、API 返回或 IndexedDB 内容。

运行中的旧版本发现新版后只提示，不强制刷新。点击“更新并重新打开”前，需保存并关闭编辑窗口、关闭其他记账标签页或桌面窗口；程序等待本地写入队列后再切换。关闭全部旧窗口后，浏览器也可按标准生命周期激活已下载的新版本。升级保留既有账目和本机保护机制。

新版本资源下载失败时，安装失败，旧版缓存继续工作。激活后保留一份旧程序缓存，其他旧缓存只按本应用的作用域前缀清理，不清理账目或其他站点数据。不要通过“清空网站数据”解决更新问题；先备份，再从设置检查更新或关闭所有窗口后重开。

发布回退：应优先构建修复版并提高应用版本号。不要随意把旧代码重新部署到更高版本数据上；现有存储保护会拒绝不兼容版本。

## 验证命令与手机验收

```powershell
npm run check
npx playwright install chromium
npm run test:e2e
npm run test:pwa
```

PWA 测试使用独立浏览器数据与 4175 测试服务器，服务完整 dist，并模拟完整更新、资源下载失败和文件分享取消；不改用户预览数据。测试服务器仅用于自动化，禁止用于正式部署。

浏览器自动化不能代替 iPhone 真机验收。正式网址发布后还需在真实设备上检查：

- Safari → 添加到主屏幕，图标清晰、独立窗口正确，金额键盘和底部保存栏不遮挡。
- 离线就绪后开飞行模式，完全关闭再重开，记一笔、看统计、导出和恢复备份。
- 加密备份确实出现在“文件”中，并能选中 `.pocket` 文件恢复；分享取消后能重试。
- 更新提示出现时草稿保留；多窗口阻止立即更新；关闭其他窗口后更新成功。
- 从浏览器入口迁移到桌面入口时核对数据；关闭 Safari/重启手机后再检查；确认持久存储实际授予结果。

当前本地实现和自动化通过情况另见 `实现与验证记录.md`。尚未发布公网 HTTPS 站点，也未在真实 iPhone 上完成以上验收。
