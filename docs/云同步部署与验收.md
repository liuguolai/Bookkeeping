# 可选云同步（PWA 0.2.2 / 安卓 0.2.3）

本版本在本地优先记账的基础上增加 Cloudflare Workers + D1 云同步。iPhone Safari、安卓浏览器、电脑浏览器及其安装到桌面的 PWA 使用同一网站和账号密码（或原同步密钥）即可同步。安卓 APK 0.2.3 接入 `https://pocket-ledger.liuguolai.workers.dev`，保留加密 SQLite 和文件备份；原生 iOS 暂不接入云端。

## 安卓 0.2.3

- APK 内置页面，首次启动即可离线创建账本；欢迎页和设置页均可账号登录或使用已有密钥连接。普通记账、统计、模板、分类等与当前共享前端同步更新。
- 账目、同步密钥和共同基线保存在同一加密 SQLite 数据库。合并同时写入账目、同步版本及保护副本；失败整体回滚。恢复本机副本会断开自动同步，清空本机不删除云端。
- 使用 Capacitor 原生 HTTPS 请求，固定到上述正式源地址并拒绝重定向；PWA 继续同源请求。服务端继续拒绝浏览器跨站请求，不新增 CORS 放行，不需要服务器升级或数据库迁移（前提是已部署 0.2.2 账号服务）。
- APK 新增 INTERNET 权限。返回前台后会继续同步；关闭或被系统挂起时不保证后台同步，未连接时仍可纯本地记账。
- 0.2.3 沿用旧 APK 的调试签名，覆盖安装保留数据；不要卸载旧版再装。更新 APK 与 PWA 的网页检查更新是不同流程，APK 本次不提供自动下载安装更新。

## 0.2.2：升级及账号密码

已部署云同步的站点，在项目根目录依次执行：

```powershell
npm.cmd run cloud:migrate
npm.cmd run cloud:deploy
```

第一条为原 D1 新增 `sync_accounts` 表（`0002_accounts.sql`），不修改原账目表内容；第二条构建并发布前后端。保留原数据库 ID、网站域名和 `SYNC_SETUP_CODE`，无需重建数据库、同步空间或创建码。`wrangler.jsonc` 新增 `AUTH_RATE_LIMIT` 绑定（10 次/60 秒）；必须连同 Worker 一起发布，不能仅上传静态 ZIP。未迁移或缺少限流绑定时，账号接口返回明确错误，原密钥同步仍可用。

部署完成后，在设置中检查更新并重新打开应用，不清除网站数据：

1. 已连接的设备：云同步 → **账号与密码**，设置账号名和密码。仍绑定原同步空间，不复制账本。
2. 尚未创建空间：按下文创建空间并保存密钥，再绑定账号。没有强制注册，本地记账仍可直接使用。
3. 另一台设备：打开同一正式网址，欢迎页 → **账号登录**，输入账号密码即可恢复；无需先建空账本。
4. 修改密码：已连接设备 → **账号与密码**。账号名不变，设置新密码；两台设备同时修改时后提交者需重新读取，避免静默覆盖。
5. 忘记账号名或密码：账号登录 → **忘记账号或密码？用恢复密钥找回**，输入原 `pl1_...` 同步密钥并设置新密码。没有邮件或短信找回。

账号名为 3–32 位英文字母、数字、下划线或短横线，以字母或数字开头，不区分大小写；不是邮箱。密码至少 8 个字符，最多 128 个输入长度单位，可使用长句或密码管理器。一个同步空间只绑定一个账号，首版不提供重命名。

**原同步密钥同时是恢复密钥，请继续保存。** 改密码不会撤销已连接设备或原密钥的访问权；本版本不提供遗失设备撤销或密钥轮换。账号密码、恢复密钥和已连接设备全部丢失时，无法解密找回云端账目，只能使用独立备份。普通备份文件不含恢复密钥。

账号密码用于联网登录，不是本机锁屏密码；断开同步仍保留本机账目。登录并连接将合并本机与该空间的账本；关联过其他空间的设备会被阻止，先备份整理再切换。

## 使用方式

1. 在“设置 → 云同步”选择“创建同步空间”，保存随机生成的同步密钥，输入网站管理员提供的创建码。
2. 另一台设备打开同一网址，在欢迎页上方“已有云端账本？”中选择“账号登录”或“使用已有密钥连接”，无需先新建空账本。没有云端空间的用户才使用下面“第一次使用？创建账本”。
3. 连接意味着同意将当前设备所有账本与该空间合并；存在修改冲突时，先选择版本再同步。
4. 本地修改保存后约 3 秒触发同步。回到前台、恢复网络也会触发；页面处于前台时约每分钟检查一次。可手动“立即同步”。iOS 关闭应用后不保证后台同步，下次打开继续。
5. 断开连接保留本机账目、账号关联及上次合并基线；重新使用原密钥连接可以继续正确处理离线删除。切换其他空间前必须先导出备份并清空本机，避免把私人账目混到另一账号。

同步密钥 `pl1_...` 是登录及解密凭证，不是普通弱密码。请保存在密码管理器；服务器不能重置或找回密钥。已连接设备可以在设置中再次查看。创建码只控制新空间注册，不是已有空间的登录密码。同步密钥不包含在普通加密备份文件中。

## 0.2.1：同步后如何找到数据

- 同步面板显示最近一次成功同步的账本和记录总数，不含回收站；有待上传修改时，这个数量仍代表上次已确认的结果。
- 若当前账本为空而其他账本有记录，设置页和明细空状态会提示切换，提供“查看全部账本”或“查看有记录的账本”。从这些入口选择有记录的账本后会进入最近记账月份，清除旧筛选。
- 同名账本按唯一编号分别保留。选择列表显示“当前”、记录数、最近记账时间；同名时额外显示创建时间和重命名提示，不自动合并或删除。
- 新设备第一次恢复时优先选择有记录的账本；已有设备的当前选择不会被后台同步强行改变。
- 本地预览明确提示与正式网站分离。两台设备必须访问同一个正式网址并使用同一个同步密钥。
- 0.2.1 原有同步密钥继续兼容；0.2.2 新增账号密码及恢复机制，详见上文。

0.2.1 未变更数据库结构；升级到 0.2.2 则需要先执行账号表迁移，按本文开头操作。

## 同步范围与保护

- 同步账本、流水（包含回收站）、分类及顺序、支付方式、预算、模板。金额与币种规则不变，不进行汇率换算。
- 草稿、当前账本选项、备份导出时间、文件恢复历史、本机保护副本只保存在设备上。被永久删除账本的本地草稿会随合并移除，合并前副本仍可恢复。
- 使用上次共同状态进行逐记录三方合并，不按设备时间强行覆盖。同一记录双端修改、删除与编辑冲突、相互矛盾的排序需要人工选择。
- 两端退款合计超额、账本删除和新增记录并发等关联冲突，以整个受影响账本选择版本，其余账本保留。全局数量超限会停止合并，不截断记录。
- 云端版本条件更新防止覆盖另一设备刚上传的内容；本地状态、合并基线和保护副本通过一个 IndexedDB（PWA）或 SQLite（安卓）事务保存，并核对本地版本及连接代次。丢失上传响应后可安全重试。
- 云端快照缺失、格式错误或版本低于本机已确认版本时停止同步，避免数据库回滚被误解为删除；保留本地数据供导出和检查。
- 应用仍先完成本地记账，上传失败不回滚账目。同步合并前自动保存本机保护副本，最多 3 份，和原有手动/升级保护共用保留数量。
- “清空全部本地数据”断开本机连接，不删除云端；恢复本机保护副本也会断开连接，防止旧副本自动覆盖云端。重新连接前可先导出当前及待恢复内容。
- 云同步不能替代独立文件备份：有意删除也会同步，管理员删除数据库或密钥遗失需要另存的加密备份。

## 加密及容量边界

设备生成 256 位随机密钥，HKDF-SHA256 按不同用途派生认证令牌和 AES-256-GCM 加密密钥。每次上传使用随机 96 位 IV，认证附加数据绑定协议版本及空间标识。账目表保存认证令牌的 SHA-256 标识、版本、更新时间和账本密文；不接收主密钥明文、账目明文或备份密码。

绑定账号时，浏览器用随机 256 位盐和 PBKDF2-HMAC-SHA256（600,000 次）处理密码，再通过不同 HKDF 用途派生登录凭证和 AES-256-GCM 包装密钥。加密包装原同步密钥，附加数据绑定账号、空间和盐；改密码只更新包装，不重加密全部账目。D1 账号表保存账号名、盐、派生登录凭证的 SHA-256 校验值、密钥密文及版本，不保存密码或主密钥明文。参数参考 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 的 PBKDF2 建议，不代表通过安全认证。

此协议不是 PAKE：请求中的派生登录凭证仍是敏感凭证，需要 HTTPS，不能记录请求体或认证头。服务器得到该登录凭证不能直接推导包装密钥，但弱密码仍可能被离线猜测。账号名不属于秘密；统一错误提示不能完全隐藏账号是否存在。服务端使用 IP 与账号登录限流，降低在线猜测风险；仍需保护托管账号、前端代码与终端设备，尚未经过独立安全审计。

本机 IndexedDB 保存账目、同步密钥及共同基线，**本机浏览器存储没有额外密码锁**，需要保护设备和浏览器访问；安卓对应内容在加密 SQLite 内，账号密码仍不是本机解锁密码。密钥不写入 URL、构建变量、请求日志或仓库。服务拒绝浏览器跨站调用，PWA 使用同源 API，安卓通过原生 HTTP 客户端访问；接口不缓存，Service Worker 明确绕过 `/api/`。这些是实现及自动测试结果，不代表独立安全审计。

首版传输完整加密快照，逐记录合并；不是逐行增量传输。每个同步空间明文快照最多 1,340,000 字节，密文信封最多 1,800,000 字节，以低于 D1 每行 2 MB 限制。超过时保留本地数据并提示，不截断、不假报同步成功。大量历史记录需后续升级分块协议，不能把本地支持的 20 万条记录理解为当前云端容量。

Workers 免费额度和 D1 配额以平台为准；一个免费 D1 数据库上限 500 MB。同步按空间每分钟 60 次请求限流，注册额外共用每分钟 60 次限制。账号接口按 IP 每分钟 10 次请求，登录还按账号每分钟 10 次限制（一次完整登录有 challenge 和 login 两次请求）；Cloudflare 限流按节点生效，不是全局计费上限。本项目不申请付费资源。

## 本地联调（不上传云端）

需要 Node.js 22.13+（推荐 24），Wrangler 已固定为开发依赖。

```powershell
npm ci
npm run build
npm run cloud:migrate:local
npm run cloud:dev
```

打开 `http://127.0.0.1:8787/`，本地专用创建码为 `local-development-only`。使用两个浏览器配置/无痕窗口测试两个设备；同一浏览器普通标签页共享 IndexedDB，不算独立设备。开发源代码热更新时另开 `npm run dev`，其 `/api` 代理到 8787。

`wrangler.local.jsonc` 只用于本地，有全零数据库 ID、公开测试创建码以及放宽到每分钟 1,000 次的账号测试限流，**不能用它部署生产环境**。

```powershell
npm run check
npm run test:sync
npm run test:pwa
npm run test:e2e
```

同步浏览器测试使用独立的 `.local/sync-test-db` 和临时浏览器上下文，不访问线上数据库。测试程序会创建合成账目。

## 首次部署到现有 Cloudflare Worker

下面步骤作用于现有 `pocket-ledger` Worker，不要改网站域名。现有静态站点部署命令仍能运行，但未绑定数据库时云同步返回“尚未配置”，本地功能正常。

1. 在本机终端登录 Cloudflare 并创建免费 D1 数据库：

```powershell
npx wrangler login
npx wrangler d1 create pocket-ledger-sync
```

2. 把创建结果中的实际 `database_id` 填入根目录 `wrangler.jsonc`，保留现有 `main`、`assets`、`ratelimits` 等字段，并增加：

```json
"d1_databases": [
  {
    "binding": "DB",
    "database_name": "pocket-ledger-sync",
    "database_id": "替换为创建结果中的真实 UUID",
    "migrations_dir": "migrations"
  }
]
```

数据库 ID 不是密钥，可以提交；不要填写全零本地 ID。CI 从仓库配置部署，单独在控制台临时绑定可能在下次部署被覆盖。

3. 应用数据库迁移并设置**运行时 Secret**，创建码使用密码管理器生成的至少 16 位随机值，命令会交互提示输入，不放到 `VITE_*` 或 GitHub 代码中：

```powershell
npm run cloud:migrate
npx wrangler secret put SYNC_SETUP_CODE
```

4. 完成本地验证后部署：

```powershell
npm run cloud:deploy
```

若继续使用 Cloudflare 的 GitHub 自动构建，构建命令保持 `npm run build`，部署命令使用 `npx wrangler deploy`。数据库迁移需要在第一次新版部署前完成，后续新增迁移也应显式执行。创建码必须属于 Worker 的运行时 Secret，不能只填在 Build variables。保留数据库配置再同步仓库，平台才会带上正确绑定。

已有纯静态 PWA ZIP **不包含 Worker 后端**。启用云同步应从完整仓库部署；静态 ZIP 仍可独立离线记账，但其同步入口需要同源后端。不要把本地配置、`.dev.vars`、数据库文件或密钥加入压缩包/仓库。

创建完自己的同步空间后，可以在 Cloudflare 控制台移除 `SYNC_SETUP_CODE` 以关闭新注册，已有空间继续正常登录和同步。若管理员需要删除云端空间，必须先让所有设备断开，另行确认数据库删除范围；本版本界面不提供云端整库删除按钮。

## 线上验收

- `/api/sync/v1/status` 返回 `enabled: true`；未携带凭证访问 vault 返回 JSON 401，不是网页 HTML。
- 手机新建空间并保存密钥，电脑用密钥连接，不创建重复账本。
- 原空间绑定账号后，在独立浏览器用账号密码登录，记录、金额、账本数保持一致；输入错误密码不改变本地数据。
- 改密码后旧密码失效、新密码可登录；原已连接设备仍可同步。使用原恢复密钥重设密码，无需记住账号名。
- 两端各离线新增不同币种记录，联网后记录都在，金额及分类顺序正确。
- 对同一记录做不同修改，显示冲突且选择前双方内容都保留。
- 删除和退款同步后仍满足回收站、同币种退款及总额约束。
- 断网重启 PWA 能记账；回到前台后恢复同步。
- 断开、清空本机不影响其他设备；本机恢复保护副本后不会自动上传。
- iPhone Safari 与主屏幕 PWA 需在真机分别验收。桌面 Chromium 手机尺寸测试不能替代这一项。

官方依据：[D1 迁移](https://developers.cloudflare.com/d1/reference/migrations/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[静态资源和 Worker 路由](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/)、[Rate Limiting API](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)。
